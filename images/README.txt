PHOTOS DU SITE

Déposez simplement ici vos photos.

Formats acceptés :
.jpg .jpeg .png .webp .gif .avif

Toutes les images de ce dossier sont automatiquement ajoutées à la galerie.

Les 4 premières images sont également utilisées en haut de la page d'accueil.
=> Il est donc conseillé de mettre vos meilleures photos en premier dans le dossier
(en les renommant par exemple 01.jpg, 02.jpg, 03.jpg, 04.jpg).

Pas besoin de modifier le HTML, JavaScript ou la configuration pour ajouter des photos.
Un git push suffit.
